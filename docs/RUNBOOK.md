# Runbook
MCP disconnect: preserve run/session metadata; reconnect and re-observe before action.
UI changed: discard stale coordinates; screenshot/analyze UI again.
Ambiguous submit: inspect resulting UI/business state before retry.
Prompt injection: stop privileged trajectory and require trusted instruction/human review.
Human takeover: pause agent actions, transfer control, resume only after fresh screenshot/state capture.
Credential exposure: terminate session, revoke credential, quarantine screenshot/log artifacts.
